# MoneyMate

A simple and practical personal finance management application designed to help users track their income, manage expenses, organize budgets, and monitor their financial activity in one place.

## Features

MoneyMate provides essential tools for managing personal finances:

* **Income Tracking** – Record and manage different sources of income.
* **Expense Management** – Track daily expenses and categorize transactions.
* **Budget Management** – Set budgets and monitor spending against available funds.
* **Transaction History** – Review previous income and expense records.
* **Financial Summary** – View total income, expenses, and remaining balance.

## Tech Stack

MoneyMate is developed using the following technologies:

| Technology | Purpose                                                                          |
| ---------- | -------------------------------------------------------------------------------- |
| Python     | Handles the application's core functionality and logic.                          |
| Tkinter    | Creates the graphical user interface (GUI).                                      |
| SQLAlchemy | Manages database operations and interactions.                                    |
| SQLite     | Stores financial records, including income, expenses, budgets, and transactions. |

## How to Run

1. Clone or download this repository.

2. Ensure Python is installed on your computer.

3. Install the required dependencies:

   ```bash
   pip install sqlalchemy
   ```

4. Run the application's main Python file:

   ```bash
   python main.py
   ```

   Replace `main.py` with the actual filename of your application's entry point if necessary.

5. Once the application opens, navigate through the available features to manage your finances.

## Conclusion

MoneyMate offers a straightforward approach to personal finance management by combining income tracking, expense monitoring, budgeting, and transaction history into a single application. With its simple graphical interface and organized financial records, it helps users monitor their spending, manage their budgets, and maintain a clearer understanding of their finances.
