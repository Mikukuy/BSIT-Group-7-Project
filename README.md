# MoneyMate
MoneyMate is as an application designed to help users manage their personal finances. It allows users to record their income and expenses, categorize transactions, and monitor their remaining budget. The system provides an organized way to understand spending habits and manage money effectively. 

## Features
This financial management system helps users keep track of their money by recording income and daily expenses, managing budgets, viewing transaction history, and checking their overall financial summary. It makes easier to monitor spending, understand where money goes, and keep track of the remaining balance.

## Tech Tack
MoneyMate is developed using Python, Streamlit, SQLAlchemy, and SQLite. Python is used to build the application's functionally, while Streamlit is used to create the user interface. SQAlchemy manages the application's database operations, and SQLite is is used to store and manage financial date such as income, expenses, budgets, and transactions.

## How to Run
To use MoneyMate, open the application and navigate through the available features. Add your sources of income and record your daily expenses with their categories. Set a budget to monitor yout spending and remaining funds, then use the Transaction History to review previous records. Finally, check the Financial Summary to view your total income, expenses, and remaining balance.

## Conclusion
Overall, MoneyMate is a simple and practical personal finance management application that helps users organize their financial information and keep track of their spending. By combining income and expense tracking, budgeting, transaction history, and financial summaries in one system, MoneyMate makes managing personal finances easier, more organized, and more convenient.
